  <img

Designed to unify investment data scattered across heterogeneous systems (Excel, Access, Oracle), the platform automates data ingestion via SSIS, delivers key indicators through Power BI dashboards secured with RLS profiling, and integrates a conversational assistant along with a SARIMA forecasting model to anticipate investment trends.

### Problem solved :
Investment contract data was spread across multiple heterogeneous systems, manually maintained, with no centralized solution—limiting consolidation, analytical monitoring, and reporting reliability for decision-makers.

### Main features : 

- Automated ETL pipeline (SSIS) with scheduled daily refresh
- Interactive Power BI dashboards with row-level security (RLS)
- Intelligent chatbot for querying data in natural language
- ML forecasting module (SARIMA, XGBoost, Random Forest) to anticipate investments
- Secure authentication and role-based user management

**Tech:** React . Node.js/Express . SQL Server . SSIS . Power BI . Python . Machine Learning

## Car Price Prediction & Market Segmentation
<a href="https://github.com/Achref-004/Car-Price-Prediction-Market-Segmentation">
  <img
    src="https://images.unsplash.com/photo-1503376780353-7e6692767b70?auto=format&fit=crop&w=900&q=80"
    alt="Car Prediction"
    width="100%"
    height="500"
  >
</a>

This project explores the Car Price Prediction Challenge dataset to build a car price prediction model and identify the main factors influencing vehicle value. After full data preprocessing (cleaning, missing value handling, categorical encoding, and standardization), a multiple linear regression model is trained and evaluated with 5-fold cross-validation. Dimensionality reduction is then performed with PCA to compare model performance using only the first two principal components. Finally, hierarchical clustering is applied to the principal components to identify vehicle segments with similar characteristics. 

### Problem solved :
Vehicle price depends on many technical and commercial characteristics. The goal is to build a reliable prediction model while reducing data dimensionality and identifying homogeneous car groups to facilitate automotive market analysis.

### Main features : 

- Exploratory analysis and dataset cleaning
- Missing value and outlier handling
- Categorical variable encoding (One-Hot Encoding)
- Multiple Linear Regression for price prediction
- Evaluation with R², RMSE, and MAE
- k-Fold cross-validation (k = 5)
- Dimensionality reduction with PCA (PC1 & PC2)
- Performance comparison before and after PCA
- Hierarchical clustering (Agglomerative Clustering – Ward Linkage)
- Cluster visualization, dendrogram, and market segment analysis

**Tech:** Python . Pandas . NumPy . Scikit-learn . Matplotlib . Seaborn . Linear Regression . Principal Component Analysis (PCA) . Hierarchical Clustering . Cross Validation

[View Car Price Predicition →](https://github.com/Achref-004/Car-Price-Prediction-Market-Segmentation)

## Full-Stack Pizza Ordering Platform

<a href="https://github.com/Achref-004/Full-Stack-Pizza-Ordering-Platform">
  <img
    src="https://images.unsplash.com/photo-1513104890138-7c749659a591?auto=format&fit=crop&w=900&q=80"
    alt="Pizza Ordering Platform"
    width="100%"
    height="500"
  >
</a>

Pizza Pete's is a food e-commerce application developed using Agile Scrum methodology. The project includes a web application built with MongoDB, Express.js, React.js, and Node.js, connected to the backend via a REST API. Users can create an account, customize pizzas, manage their cart, place orders, view order history, save favorite pizzas, and track order status in real time.

### Problem solved :
Customers need a simple and intuitive solution to order customized pizzas online. The project aims to deliver a smooth web experience with secure authentication, advanced product customization, and complete order tracking

### Main features : 

- Secure JWT authentication (sign-up and login)
- User profile management
- Order history and favorites management
- Custom pizza creation (size, crust, toppings)
- Quick Options: New Order, Re-order My Fave, and Surprise Me
- Dynamic cart with order editing and removal
- Automatic total price calculation
- Order status tracking (Preparing, Out for Delivery, Completed)
- MERN web application
- Development following Agile Scrum methodology

**Tech:** React.js . Node.js . Express.js . MongoDB . REST API . JWT Authentication . JavaScript . Git . Scrum
